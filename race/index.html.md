# Wakora streak race — join an invite

Someone invited you to a wake-up streak race on Wakora. Whoever keeps their morning promise the
most days in a row wins.

Open the invite link on an iPhone with Wakora installed and the race starts automatically; the
race ID is read from the address. If you do not have the app yet, install it first:
https://apps.apple.com/app/id6761144895

- Wakora: https://wakora.app/
- What Wakora is: an iPhone alarm that can only be dismissed by completing a wake-up mission.
